ABSTRACT
This project presents AI Traffic Quantum Pro, an advanced intelligent traffic management system that transitions traditional static signal control into an adaptive, real-time mechanism. Operating within a high-fidelity 3D CARLA simulation environment representing a living city with over 20 autonomous agents, the system bridges real-time computer vision perception with quantum-inspired decision-making. A YOLOv8 model serves as the perception layer, processing camera sensor streams at an ultra-fast 10ms per frame to detect vehicles at major intersections. These detections are mapped into an 18-feature state vector comprising 9 vehicle density values and 9 signal states. This state vector is transferred via a synchronized real-time JSON file-drop bridge to the backend controller. The backend leverages a 9-qubit quantum-inspired reinforcement learning model trained over a 5-million-step marathon session to optimize traffic phase selection dynamically. Implemented efficiently on consumer-grade hardware like an RTX 3050 GPU using precise VRAM optimization constraints, the architecture ensures complete closed-loop modular control without simulation instability. The outcome shows enhanced intersection throughput and reduced vehicle wait times under complex traffic congestion scenarios. 
Keywords: Intelligent Traffic Control, CARLA Simulator, YOLOv8, Quantum Reinforcement Learning, Digital Twin, Real-Time JSON Bridge

CHAPTER 1: INTRODUCTION
Background of Study 
Traditional metropolitan traffic signal control relies heavily on predefined static timers that fail to adapt to variable intersection volumes, leading to gridlock and elevated vehicular emissions. Recent engineering trends emphasize the development of a "Digital Twin" to model infrastructure dynamically. By transitioning from elementary 2D grid environments to hyper-realistic 3D simulators, researchers can safely deploy, test, and validate complex adaptive algorithms under synthetic urban loads.
Problem Statement 
While modern vision-based systems can process raw sensor streams to identify objects, standard implementations create isolated data silos where the vision component perceives vehicle presence without establishing a closed-loop channel to update traffic signals interactively. To construct a truly intelligent controller, systems must extract computer vision metrics dynamically, structure them into dense state configurations, and stream them securely to mathematical optimization cores running real-time control actions.
Objectives of the Project 
 To design and initialize a stable 3D simulation framework utilizing the CARLA engine to act as a real-time urban Digital Twin.
 To implement a YOLOv8-driven computer vision layer capable of tracking vehicles and executing low-latency edge-inference tracking.
 To construct a data bridge utilizing structured file-drop protocols to convert raw detections into real-time state information.
 To deploy a 9-qubit quantum-inspired reinforcement learning decision module to evaluate phase control dynamically.
1.4 Scope of the Project 
The boundary of this architecture covers the edge integration of multi-terminal automation scripts on standard processing units. It encompasses low-level client-server network initialization via the CARLA Python API, object bounding-box processing, and localized cross-process parameter passing using shared JSON states, validating optimized execution parameters specifically tailored for mid-tier graphics hardware configurations.
CHAPTER 2: LITERATURE REVIEW / ANALYSIS
2.1 Related Work 
Prior intelligent transportation models focused primarily on single-agent reinforcement learning deployed within simplified, discrete cellular automata models or 2D traffic spaces. While those approaches minimized initial compute constraints, they introduced severe reality gaps due to their complete omission of physical camera properties, variable sensor noise, multi-lane occlusion, and erratic vehicle acceleration profiles.
2.2 Comparative Study 
Traditional Rule-Based Control: Rely on induction loop hardware sensors; completely blind to non-lane vehicle clustering and pedestrian bottlenecks.
Standard Deep RL Controllers: Demand millions of training operations within 2D frameworks; suffer from high dimensionality issues when scaled across wide multi-phase intersections.
Proposed Quantum-Inspired Vision Framework: Extracts multi-lane density vectors instantly using a unified YOLOv8 parser and maps state coordinates directly to a compact 9-qubit quantum bottleneck layer to optimize multi-phase convergence rates.
2.3 Feasibility Study 
2.3.1 Technical Feasibility
The deployment is technically viable through the coordination of dedicated processing instances. Computer vision streaming requires specialized graphic memory optimizations. By leveraging specialized software runtime properties—including structural sub-sampling and target frame capping—the processing demand matches consumer hardware specifications.
2.3.2 Economic Feasibility 
By executing the complete stack inside an open-source virtual simulation pipeline (CARLA) combined with free, publicly accessible object detection weights (YOLOv8), the project demands zero financial investments in physical tracking hardware, municipal infrastructure, or proprietary licensing.
2.3.3 Operational Feasibility
The multi-terminal setup isolates the simulation environment from the analytical backend execution. If individual vision listeners or data aggregators experience terminal interruptions, the persistent simulation loop continues running independently while backend handlers initiate automated fallback operations.
CHAPTER 3: SYSTEM DESIGN
3.1 System Architecture 
The platform utilizes an decoupled, multi-terminal modular design across four distinct standalone processing processes:
The World Simulator (Terminal 1): Governs the 3D physics rendering engine and manages environmental state updates.
The Perception Module (Terminal 2): Connects to RGB virtual camera feeds, runs YOLOv8 model inference, and tracks object bounding areas.
The Living City Generator (Terminal 3): Spawns autonomous vehicular traffic flows and coordinates active traffic manager background behaviours.
The Master Controller (Terminal 4): Reads structural data streams, processes information against the 9-qubit algorithm logic, and passes light overrides back to the simulator engine.

CHAPTER 6: CONCLUSION & FUTURE WORK
Summary of project 
The AI Traffic Quantum Pro architecture successfully demonstrates a functional closed-loop traffic control framework operating within a detailed 3D Digital Twin environment. By separating perception systems from the backend core logic, the system runs smoothly across multiple terminal windows without causing resource lockouts or simulation crashes on standard hardware setups.
Achievements 
Deployed a modular multi-terminal architecture that connects simulation steps directly with deep learning layers.
Optimized a real-time YOLOv8 computer vision script to achieve ultra-fast 10ms tracking speeds on an edge GPU.
Designed and tested a functional JSON data bridge that maps visual vehicle locations into structured 18-feature state representations.
Limitations 
The platform currently relies on a local file-drop JSON architecture. While this approach simplifies local debugging, it introduces microsecond storage delays compared to network socket solutions. Additionally, system performance has only been validated under uniform environmental conditions with a fixed camera setup.
Future Scope
Advanced Anomaly Handling: Program custom edge scenarios to test system response against random pedestrian crossings and unexpected road blockages.
Emergency Override Integration: Train the vision network to identify distinct vehicle silhouettes, like ambulances, to trigger automatic priority signal patterns.
High-Throughput Network Migration: Replace local file access routines with direct TCP Network Sockets to improve communication speed and match industrial telemetry standards.
